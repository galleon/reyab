Everything runs in one docker compose on a single GPU host. VS Code, through the Continue or Cline extension, talks only to agentrouter, an Envoy gateway, which lists just the two open models. Cline sends one request per agent step, so each step is shadowed separately. The Lua filter checks the team key, reads the requested model and sends the turn to qwen3-coder or gpt-oss; for the hidden model auto, vLLM Semantic Router chooses. The answer streams straight back. At the same time Envoy mirrors the request to the recorder, which sends it to Claude Opus, tags it with NVIDIA's prompt classifier and stores both answers in bench.db. Those pairs feed the LLM judge, the blind arena votes and the Grafana dashboard. Organizers also have a localhost-only listener on 8081 exposing all three models for offline task evals.
